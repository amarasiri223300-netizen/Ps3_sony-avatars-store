# متجر افتارات سوني 3 — نسخة جاهزة للفهرسة

## قبل النشر
استبدل `https://YOUR-DOMAIN.com/` في:
- index.html
- robots.txt
- sitemap.xml

باسم الدومين الحقيقي للموقع.

## بعد رفع الموقع
1. افتح Google Search Console.
2. أضف الموقع وتحقق من ملكيته.
3. أرسل `https://YOUR-DOMAIN.com/sitemap.xml` من قسم Sitemaps.
4. استخدم URL Inspection لطلب فهرسة الصفحة الرئيسية.

ملاحظة: تجهيز الموقع للفهرسة لا يضمن ظهورَه فورًا أو في المرتبة الأولى؛ Google يقرر الزحف والفهرسة والترتيب آليًا.
